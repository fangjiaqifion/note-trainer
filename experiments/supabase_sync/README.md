# 同步队列试验

这是与游戏隔离的合成数据原型，不连接 Supabase，也不读取或上传学生数据。
运行 `node --test experiments/supabase_sync/queue.test.mjs`。

队列先持久化再发送，完整确认后才删除已发送项。服务端必须持久化唯一事件 ID，
并将重复提交作为幂等操作处理；本原型的模拟服务只用于测试，不能代替真实服务验证。
队列持久化失败、返回不完整回执或网络失败都不能标为成功。

未实现：游戏事件接入、Supabase 认证和 API、服务端幂等校验、恢复与备份、
跨设备身份映射、冲突处理、设备实测或生产部署。不得用于真实学生数据。
