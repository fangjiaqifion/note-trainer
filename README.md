# 识谱小练习 · note-trainer

给初学钢琴的孩子每天练 3 分钟的单页小游戏。只练一条链子：音名 → 键盘位置 → 五线谱 → 时值 → 手与指法。

**在线玩**：https://fangjiaqifion.github.io/note-trainer/

当前是**第一单元**，三个音（B3、中央 C、D4）配四种时值（四分、二分、附点二分、全音符）。音不是写死的，加音只改一处配置，见下面「单元：怎么加音」。

## 怎么开始

1. iPad 用 Safari 打开上面的网址。
2. 点「分享 → 添加到主屏幕」。之后全屏打开，像一个 App，断网也能玩。
3. 挑一关开始，第一次建议「轻松」档。

不联网、无外部依赖。声音由 Web Audio 合成，题目用系统中文语音念出来，孩子不识字也能独立操作。星星存在本机，下次打开还在。

## 四关

| 关卡 | 题目 | 判定 |
|---|---|---|
| 1 键盘上的位置 | 屏幕给一个音名（B / C / D），在两组键盘上点出来 | 不区分音组，点中任何一个同名键都算对 |
| 2 五线谱 ↔ 键盘 | 双向轮换：给谱面点键盘，或高亮一个键从几张谱例里选 | 要对上具体音组，并且认对谱号 |
| 3 几拍 | 看符头与符杆判断时值，选 1–4 拍；或问「哪个是二分音符」 | 四分 1 拍、二分 2 拍、附点二分 3 拍、全音符 4 拍；答对后按真实拍长发声，下方一拍亮一颗圆点 |
| 4 手、指与拍数 | 看符杆判左右手；看数字与位置点出音；按住琴键弹足长度 | 指法与手按上表；按住时长要够这个音符的拍数 |

第 4 关不告诉孩子是几拍，只给谱面。按住期间每过一拍亮一颗圆点，音持续响；松手不够长会提示「这个音符是 3 拍，你按住了 2 拍」。

每关的题从题库随机抽、顺序随机（「按住」不会排在第一题）。每关一次答对 7–8 题（挑战档 9–10 题）得三颗星。

## 谱面约定

| 音 | 谱号 | 位置 | 手 | 符杆 | 指法 |
|---|---|---|---|---|---|
| B3 | 低音谱号 | 上加一间（五线之上那一格） | 左手 | 朝下 | 2 |
| 中央 C | 高音谱号 | 下加一线 | 右手 | 朝上 | 1 |
| D4 | 高音谱号 | 下加一间 | 右手 | 朝上 | 2 |

符杆方向表示左右手：右手朝上，左手朝下。指法数字写在音符外侧。这和纸面谱一致，孩子换回纸质谱不用重新学。

## 难度

| 档 | 选项数 | 提示时机 | 拍速 | 题量 |
|---|---|---|---|---|
| 轻松 | 2 个 | 错 1 次就提示 | 52 BPM | 8 |
| 标准 | 3–4 个 | 错 2 次提示 | 60 BPM | 8 |
| 挑战 | 3–4 个 | 错 3 次提示 | 76 BPM | 10 |

拿到三颗星后，结算页会出现「试试挑战」，一点就升档并重开这一关。星星只记最高值。

节日装饰（万圣节前后）自动开启，设置里可以手动关掉。

## 单元：怎么加音

游戏不把三个音写死在关卡里，配置在 `index.html` 顶部：

```js
const NOTES = {
  B3: { id:'B3', letter:'B', label:'B',      midi:59, clef:'bass',   y:-0.5, hand:'L', finger:2 },
  C4: { id:'C4', letter:'C', label:'中央 C', midi:60, clef:'treble', y:5.0,  hand:'R', finger:1 },
  D4: { id:'D4', letter:'D', label:'D',      midi:62, clef:'treble', y:4.5,  hand:'R', finger:2 }
};
const UNIT = { name:'第一单元', label:'B · 中央 C · D', notes:['B3','C4','D4'] };
```

加一个新音两步：

1. 在 `NOTES` 里加一条，填 `midi`、`clef`、`y`、`hand`、`finger`。
   - `y` 是音符在谱表上的纵向位置，以线距为单位：`0` 到 `4` 是五条线，`4.5` 是底线下方的一间，`5` 是下加一线，负数往上。
   - 需要加线时登记到 `LEDGER`，例如 `LEDGER.treble.A3 = 6`。
2. 把 id 放进 `UNIT.notes`，顺手改 `UNIT.name` / `UNIT.label`。

关卡会自动用上新音：第 1、2 关按 `NOTE_IDS` 出题，第 3、4 关的题库跟着扩。第二单元（比如高音谱号的 E F G）可以复制一份目录单独改 `UNIT`，也可以并进同一个单元。

## 在 iPad 上打开

### 线上（推荐）

https://fangjiaqifion.github.io/note-trainer/

HTTPS 下会自动注册离线缓存（`sw.js`），第一次打开后断网也能玩。改完代码推上去，等 GitHub Pages 重建（约一分钟），刷新即可。

### Mac 当服务器（改代码时用）

```bash
bash games/note-trainer/serve.sh          # 默认 8765
bash games/note-trainer/serve.sh 8080     # 换端口
```

脚本打印两个地址：Mac 上用 `http://127.0.0.1:8765/index.html`，iPad 上用 `http://<Mac 的局域网 IP>:8765/index.html`。iPad 要连同一个 Wi-Fi，Mac 睡眠就断。

## 改代码

- 单文件网页，改完刷新就生效，没有构建步骤，也没有依赖。
- 调试入口：`window.__dbg` 下有 `G`（当前关卡与题目）、`NOTES`、`VALUES`、`UNIT`。
- 改完至少过一遍四关，并在 iPad 竖屏看一眼版式。

### 仓库与提交

- GitHub：https://github.com/fangjiaqifion/note-trainer
- 这个目录本身也是 git 仓库，`.git` 在目录内，Nutstore 会一起同步；历史另有 GitHub 一份，两边互相备份。

## 素材来源

高音谱号取自 Wikimedia Commons 的 `Treble clef.svg`（作者 Tlusťa），低音谱号取自 `Clef Bass (F).svg`，都是公有领域。两条路径已烘焙进 `index.html`，运行时不需要网络。

## 已知限制

- 网页判断不出孩子用了哪根手指；第 4 关的指法是识记与读谱，手的动作靠家长在琴上核对。
- 「按住」只判断时长，判断不了是哪根手指按的。
- iOS 的静音开关会同时静音 Web Audio。没声音时先到「设置 → 试听」点一下：有「咚」和一句中文就说明页面正常，问题在系统音量或静音开关；连试听都无声，再看侧边开关。
- 语音依赖系统语音包：汉字用中文声音，B / C / D 用英文声音读字母本音。缺语音包时只显示文字。
- 横屏时谱面按高度缩放，纸面会收窄，属正常自适应。
- 星星与设置存在 `localStorage`，换设备或清网站数据会丢。
